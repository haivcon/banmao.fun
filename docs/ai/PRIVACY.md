# AI privacy

Default local policy: no durable server conversation memory. The browser may retain the current tab's messages only; closing or clearing the panel removes them. Wallet hints are not proof of ownership. Raw prompts, wallet addresses, credentials, upstream payloads, and tool payloads must not be logged.

Production retention, export/delete guarantees, consent copy, pseudonymous identifiers, and store TTL remain blocked on privacy/security owner approval. Until approved, server memory stays disabled.
