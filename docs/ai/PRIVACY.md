# AI privacy

Default local policy: conversation persistence is off and there is no durable server conversation memory. With persistence disabled, chat state remains in memory for the current page session and prior turns are not sent as conversation context. When the user explicitly enables conversation persistence, versioned sessions are stored in IndexedDB in this browser, subject to a 500,000 estimated-token cap per session; at most 12 recent complete messages within the request token budget are sent with the next request. Disabling persistence stops subsequent durable writes but does not silently delete previously saved sessions; users can clear or delete them explicitly. Browser wallet state is never sent with chat requests. Proof-of-wallet is handled only by the separate SIWE-protected transaction prepare/simulate flow. Raw prompts, conversation history, wallet addresses, credentials, upstream payloads, and tool payloads must not be logged.

Production retention, export/delete guarantees, consent copy, pseudonymous identifiers, and store TTL remain blocked on privacy/security owner approval. Until approved, server memory stays disabled.
