# Project context

- BanmaoBox must emit `MetadataUpdate(tokenId)` immediately after every successful `_safeMint` on every mint path. Observed OKX media ingestion requires this explicit ERC-4906 signal; `createBoxes` emits one signal per minted token.
- BanmaoBox symbol presentation preserves non-generic stored snapshots. Literal `TOKEN` or empty snapshots use a bounded live ERC-20 `symbol()` read with safe Unicode validation and fall back to localized TOKEN plus a shortened token address; frontend preview/copy must use the same rule as the active Renderer.
- BanmaoBox transaction notifications use the shared `react-hot-toast` region. Wallet rejection must state that nothing was submitted; replacement and receipt timeout may link the known transaction hash without claiming confirmation.
- BanmaoBox collection creation, verification, selection, history/admin verification, and deployment summaries show every token, collection, Factory, Renderer, and transaction address/hash in full as copyable explorer-linked text with mobile-safe wrapping. Only ordinary compact NFT-card fallback symbols may include a shortened token address.
- Automatic BanmaoBox Explorer verification accepts only a creation transaction hash, derives constructor inputs from the validated chain-196 Factory receipt and creation-block state, and uses the immutable Factory-era verification release. BanmaoBox collections are direct non-proxy deployments: proxy verification endpoints are forbidden. Ambiguous submissions are quarantined for polling/reconciliation rather than resubmitted.
- Public-source readiness requires `npm run check:generated`; the canonical current BanmaoBox release has compiler input hash `0x22aad5bfec33af537e970ff3f2cca2f43d7ebfe63d1c537712d9ecb8728ebc8d`, and its Renderer runtime is 19,214 bytes with keccak256 `0xd69507283765b914480cf8aa8a8f37f4bbd351b0620ede3b0bbd5e3ca390f703`.
- The repository's pre-public full-history audit found a historical Cloudinary credential in `fetch_all.js`; public visibility remains blocked until the credential is rotated/revoked and Git history is remediated and rescanned.
