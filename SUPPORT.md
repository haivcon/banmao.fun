# Support

## Product and usage questions

Use [GitHub Discussions](https://github.com/haivcon/banmao.fun/discussions) when available, or open a [configuration/support issue](https://github.com/haivcon/banmao.fun/issues/new/choose) with the relevant route, browser, wallet, network, and public transaction hash.

Community links are available from [banmao.fun](https://www.banmao.fun/). Maintainers cannot recover wallets, reverse transactions, bypass BanmaoBox timelocks, or guarantee support for third-party tokens and services.

Never share a seed phrase, private key, API credential, session secret, or private user data. Anyone asking for those values is not providing legitimate project support.

## Bugs and features

Use the repository issue templates for reproducible bugs and feature proposals. Search existing issues first and include only sanitized logs.

## Security

Do not request security help in a public issue. Follow [SECURITY.md](SECURITY.md) and submit a private GitHub Security Advisory.
